English Finder

Finds English text on translated pages: sentences, paragraphs, headings, button and link labels, image alt text, menus and page meta. It highlights each one and lets you jump to it from a list.

English Finder Drag this button to your bookmarks bar. Bookmarks bar hidden? Press Ctrl+Shift+B (⌘+Shift+B on Mac).
Dragging doesn't work? Copy the code instead

Create a new bookmark, name it English Finder and paste this into the URL field.

Use it

  1. Open a translated page, for example phonak.com/de-de/….
  2. Click the bookmark. Every English piece is highlighted and listed in the panel.
  3. Click an item to scroll to it. A red ring pulses on the exact text.
  4. Click the bookmark again, or ✕, to remove everything.

What it does

  • Sentence-level detection. In a German paragraph with one English sentence, only that sentence is marked.
  • Colour by type. Heading, paragraph, CTA / link, label, menu / footer, asset (alt text, PDF links) and SEO meta. Filter with the chips.
  • Jump and step. Previous / Next buttons, or Alt+J / Alt+K. Alt+H toggles highlights.
  • Opens hidden content. If the text sits in an accordion, tab or <details>, it tries to open it first. Carousel slides you still have to advance yourself.
  • AEM context. Each item shows the nearest heading and the cmp-… component name, so you know which component to open in the editor.
  • Compare with EN. Reads the page's hreflang English alternate (falls back to a guessed /en-int/ URL), fetches it, and flags text that is identical there, meaning it was never translated.
  • Export. Copy a Jira table, copy for Excel, or download a CSV with type, text, section, component, selector and visibility.
  • Tuning. Strict / Balanced / Loose sensitivity. ✕ on an item ignores it on that site. Ignore words teaches it product names such as new hearing aid families.

Good to know

  • Detection uses word lists, so very short or brand-heavy strings can be missed or wrongly flagged. Use Loose to catch more, or ✕ and Ignore words to quiet false hits.
  • It reads what is on the page when you click. Content that loads later needs Rescan.
  • Needs Chrome or Edge 105+, Safari 17.2+ or Firefox 140+. Some sites block bookmarklets with a strict content security policy; most AEM sites do not.
  • Nothing leaves your browser except the fetch to the English page in Compare with EN.
